# Solar Energy Management Frontend

A React and Vite dashboard for the Solar Energy Management backend.

## Run locally

```bash
npm install
npm run dev
```

The development server uses `http://localhost:9090/graphql` through the Vite proxy.
Copy `.env.example` to `.env.local` and set `VITE_GRAPHQL_URL` if needed.

## Available scripts

```bash
npm run dev
npm run build
npm run lint
npm run preview
```
